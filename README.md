# mapronds
Map of restaurants for the Restos Ronds club (data: RESTOS_RONDS Google Sheet), at ronds.thenines.club.

- Every restaurant row carries `club_id = 2` (Les Ronds), the same club ids as the members sites
  (The Nines = 1). A `club_id` column in the sheet, if one is added, takes precedence.
- **Planned, not built:** the map stays public for now. Later, members signed in to Les Ronds may see
  extra detail about their own club's dinners; the `club_id` on each row is what that will use.
